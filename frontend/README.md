## 🤖 Highspring Hub Assistant

The homepage includes an embedded **Highspring Assistant** accessible via:
- Floating launcher at the bottom-right corner (`Hub Assistant`)
- Quick header button (`Hub Assistant & Manuals`)

### What the Assistant Does:
- **Answers questions about the Hub**: "What is this app?", "Provide an overview of this app", etc.
- **Explains what each tool does**: "What does the Interview tool do?", "How does Rating Automation work?", etc.
- **Direct User Manual Access**: Instant summaries and one-click launch buttons to the official Google Docs operations manuals.
- **Search Capabilities**: Searches across tools and capabilities by natural language queries.
- **One-click Launch Actions**: Direct launch action buttons embedded inside chat messages.
